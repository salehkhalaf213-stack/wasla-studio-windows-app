# موقع WASLA STUDIO التسويقي

صفحة هبوط عربية ثابتة ومستقلة عن تطبيق Windows ونسخة الويب داخل `WASLA_STUDIO_Desktop`. لا تستدعي قاعدة بيانات المنصة ولا تغيّر إعدادات الموقع الحالي.

## النشر المجاني المؤقت عبر Cloudflare Pages

أنشئ **مشروع Pages جديداً** في حساب Cloudflare، ولا تربطه بمشروع الاستضافة الحالي:

- Repository: `salehkhalaf213-stack/wasla-studio-windows-app`
- Production branch: `feature/wasla-landing-page`
- Root directory: `marketing-site`
- Build command: اتركه فارغاً (HTML/CSS/JS ثابت).
- Build output directory: `.`
- Framework preset: `None`

بعد إكمال الربط، ستنشئ Cloudflare عنواناً مؤقتاً مجانياً بصيغة `<project-name>.pages.dev`. لا يتم النشر تلقائياً من هذا المستودع؛ يجب إكمال ربط المشروع من لوحة Cloudflare بحساب المالك.

## بعد ظهور رابط Pages

1. افتح رابط `pages.dev` واختبر الصفحة على الهاتف والكمبيوتر.
2. استبدل `YOUR-DOMAIN-HERE` في `index.html` و`robots.txt` و`sitemap.xml` بعنوان النطاق النهائي عندما يتوفر.
3. أضف الدومين المدفوع لاحقاً من إعدادات Custom domains في مشروع Pages نفسه.

## حدود مهمة

- لا تغيّر أو تحذف موقع WASLA الحالي أو إعدادات Netlify الخاصة به.
- لا توصل صفحة الهبوط بقاعدة بيانات الإنتاج أو بمفاتيح سرية.
- روابط دخول المنصة تبقى كما هي حالياً.
- طلبات الاشتراك عبر واتساب يراجعها المسؤول يدوياً؛ الصفحة لا تفعّل اشتراكاً ولا تسجل دفعة تلقائياً.
- الأسعار وبيانات الدفع المعروضة يجب مراجعتها واعتمادها قبل الإعلان العام.
- لا يتم اعتماد أو دمج هذا الفرع إلى `main` ضمن هذا العمل.
